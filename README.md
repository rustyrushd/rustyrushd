## Some Stuff

### Object Orientated Programming (OOP)

The following repositories demonstrate introductory coursework in OOP using 
Java.

- [uni-oop-java-01-objects](https://github.com/rustyrushd/uni-oop-java-01-objects)
- [uni-oop-java-02-classes](https://github.com/rustyrushd/uni-oop-java-02-classes)
- [uni-oop-java-03-collections](https://github.com/rustyrushd/uni-oop-java-03-collections)
- [uni-oop-java-04-excep_handling_io](https://github.com/rustyrushd/uni-oop-java-04-excep_handling_io)
- [uni-oop-java-06-unit_testing](https://github.com/rustyrushd/uni-oop-java-06-unit_testing)
- [uni-oop-java-07-code_coverage](https://github.com/rustyrushd/uni-oop-java-07-code_coverage)
- [uni-oop-java-08-inheritance](https://github.com/rustyrushd/uni-oop-java-08-inheritance)

The concepts covered are Version Control Systems (VCS), Objects, Classes, 
Collections, Exception Handling, File I/O, Unit Testing, Test Driven Development
(TDD), Code Coverage, Inheritance, Unified Modeling Language (UML) Class 
Diagrams, Polymorphism, Interfaces, Application Programming Interfaces (API), 
Databases, Create Read Update Delete (CRUD), Project Management, Agile and 
Scrum. 
Google Java Style Guide is followed.

I've included a `CHANGELOG.md` in each repository where all notable changes to 
each project are documented, as opposed to noisy commit histories.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Projects adhere to modified Semantic Versioning [(MAJOR.MINOR.PATCH)](https://semver.org/spec/v2.0.0.html),
where a 1.0.0 is achieved when specified coursework criteria is met and MINOR 
increments correspond to implementing educational components as they arise 
throughout the course.
